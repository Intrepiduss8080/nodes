# Lua


Lua - it is a dynamic scripting language.  Its lightweight and embeddable, using in the gaming industry, data bases, network analysis, web-servers and proxy's.

* #  The interpreter is written in ANSI C, weights several hundred kilobytes & easily integrates into systems written in C & C++. 

* ## It has 8 data types: nil(like null), boolean(logical), number(numbers), string(strings), function(functions), userdata(data from C & C++), thread(coroutines) and table(tables).

* ### Table is the main data structure that replaces arrays, lists, hash-tables and servers as the main implementation of OOP.


* #### It has dynamic data typing.
